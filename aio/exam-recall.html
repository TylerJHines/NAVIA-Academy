    Manifest file editor
    Start with a blank file and write the YAML yourself. Press Ctrl+O (or click Write Out) to save; press Ctrl+X to exit the editor. Neither key combination is a shell command. The file exists in the simulator only after saving. Ctrl+X closes the editor without saving any unsaved edits. You can verify it with cat /home/student/jobs/training.yaml.
